# 🌸 Discord-Chan v2.6.0: All-Custom & Modular Extensions Release

Welcome to the official release of **Discord-Chan v2.6.0**!

### 🌟 What's New in this Major Update:
- 🔘 **Master Theme Switch (ON / OFF):** Easily toggle custom themes on or off with 1 click. When turned OFF, Discord seamlessly returns to 100% vanilla default without uninstalling.
- 🪟 **3 Display Architectures:**
  1. *Anime Wallpaper Mode:* High-res anime art with fine-tuned overlay darkness.
  2. *See-Through Window Transparency Mode:* View apps and desktop behind Discord through translucent acrylic glass!
  3. *Vanilla Discord Mode:* Standard native Discord client.
- 💬 **100% Glass Chat Column:** Overrides Discord design system tokens (`--background-primary`, `--bg-base-primary`, `--chat-background`) so wallpapers shine through completely without solid grey blocks.
- ✏️ **Native Styled Chat Input Bar:** Translucent glass text box matching Discord's native layout, with accent focus glow and clean action buttons.
- 📐 **UI Corner Radius Customization:** Slider from sharp `0px` to rounded `24px` for chat boxes, embeds, modals, and buttons.
- 🎴 **Embeds Styling Fix:** Eliminates muddy shadows. Embeds render as clean translucent cards with solid left color accent bars.
- 🧩 **Chrome-Style Extension System (.zip):** Install community add-on extensions packaged in `.zip` format (`manifest.json` + `style.css`), or generate ready-to-edit extension templates.
- 📦 **Theme Packager (Export & Import .zip):** Export your complete theme (parameters + CSS + embedded wallpaper) to a single `.zip` file, and import community themes with 1 click.
- 🐱 **Clean Mascot Icon:** Original Discord-Chan Neko mascot in a natural squircle without harsh borders or desktop clutter.
- ⚡ **Zero-Lag & Anti-Collision Engine:** High-performance 60 FPS CSS without heavy box-shadows. `top-spacing` prevents header collision with window panels.
- ⌨ **In-Discord Hotkey (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>):** Open the Studio & Command Palette directly inside Discord or globally from any window!
- 👤 **Lead Contributor Profile:** Created and maintained by **myzert** (`zerttcihuy@gmail.com`).
- 🛡️ **100% Client-Side CSS (ToS Safe):** NOT a Nitro modification. 100% safe, aesthetic-only BetterDiscord styling.
- 📚 **Official GitHub Wiki Documentation enabled.**
