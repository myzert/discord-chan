# 🪟 Discord-Chan Display Modes

Discord-Chan Studio allows you to switch between 3 primary display architectures:

### 1. 🌸 Anime Wallpaper Mode
Renders high-definition anime backgrounds (such as *Kaede to Suzu The Animation*, *Whisper Me a Love Song*, or any custom image chosen from your hard drive).
- Chat column is 100% translucent, allowing full artwork visibility.
- Dark overlay level can be fine-tuned via the slider to ensure text readability.

### 2. 🔍 See-Through Window Transparency Mode
Makes Discord's window transparent so applications and your desktop behind Discord are visible!
- Wallpaper layer is disabled.
- Subtle background tint (configurable from 10% to 85%) creates an acrylic glass aesthetic.
- Requires `--enable-transparent-visuals` (automatically configured by our installer).

### 3. 🛡️ Vanilla Discord Mode (Theme Disabled)
Reverts Discord back to standard native client appearance with zero custom styles applied. Useful for testing or when you want pure vanilla Discord.
