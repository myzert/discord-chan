## Crucial Safety Notice (Terms of Service Compliance)

> [!IMPORTANT]
> **Discord-Chan is a 100% Client-Side Aesthetic CSS & BetterDiscord Theme Customizer.**
> - **NOT A NITRO UNLOCKER / MOD:** This project **does NOT unlock paid Discord Nitro perks** (no server boosting, no paywall bypasses).
> - **NO CORE BINARY TAMPERING:** We do not touch Discord server APIs, user tokens, or private messages.
> - **100% SAFE & BAN-FREE:** It purely modifies client-side CSS styling (colors, glass translucency, wallpapers, and chat avatar alignment) through standard BetterDiscord theme injection.

## 1-Command Instant Setup

### Linux (Universal Terminal One-Liner)
Run this single command in your Linux terminal:
```bash
curl -fsSL https://raw.githubusercontent.com/myzert/discord-chan/main/install.sh | bash
```

*Or clone and execute manually:*
```bash
git clone https://github.com/myzert/discord-chan.git
cd discord-chan
chmod +x install.sh
./install.sh
```

### Windows (PowerShell One-Liner)
Open PowerShell and run:
```powershell
irm https://raw.githubusercontent.com/myzert/discord-chan/main/install.ps1 | iex
```

*Or download the repository and double-click `install.bat`.*

## What's New & Core Features

| Feature | Description |
| :--- | :--- |
| **Master Theme Switch (ON / OFF)** | Enable or disable the entire custom theme with 1 click. When turned OFF, Discord returns immediately to 100% vanilla default. |
| **3 Display Architectures** | Choose between **Anime Wallpaper Mode**, **See-Through Window Transparency** (see applications and desktop behind Discord), or **Vanilla Discord**. |
| **100% Glass Chat Column** | Fixed all solid-grey background blocks by overriding Discord's core design tokens. Anime art shines through with zero obstruction. |
| **Native Styled Chat Input Box** | Text input area mirrors Discord's native chat bar with translucent glass, accent glow on focus, and clean action buttons. |
| **UI Corner Radius Customization** | Slider from sharp `0px` to rounded `24px` to customize the curvature of chat boxes, embed cards, modals, and buttons. |
| **Embeds Styling Fix** | Eliminates muddy shadows and laggy gradients. Embeds render as clean translucent cards with solid left color accent bars. |
| **Chrome-Style Extension System (.zip)** | Install community add-ons packaged in `.zip` format (`manifest.json` + `style.css`), or generate boilerplate extension templates. |
| **Export & Import Theme Bundles (.zip)** | Share your custom themes with friends! Exports all parameters, CSS, and embedded wallpapers into a single `.zip` file. |
| **Zero-Lag & Anti-Collision Engine** | Eliminates CPU-heavy `box-shadow` and `backdrop-filter: blur`. Configurable `top-spacing` prevents header collision with window panels. |
| **In-Discord Command Palette (`Ctrl+Shift+P`)** | Launch the Studio Control Center directly from inside Discord or desktop with `Ctrl+Shift+P`. |
| **1-Click INSTALL Action** | Prominent INSTALL button in the Studio rail that automatically injects BetterDiscord and transitions directly into the Theme Manager. |
| **Theme Manager & Visual PV Showcase** | Formerly Wallpaper Manager, now an all-in-one Theme & UI Mod Hub featuring visual PVs, detailed mod descriptions, live specs, and 1-click theme application. |
| **BetterDiscord Theme Studio & Customizer** | Upload ANY BetterDiscord theme (`.theme.css` / `.css`) directly into the app, customize with a live visual color picker, wallpaper replacer, and full multi-line CSS code editor with Find & Replace. |
| **BetterDiscord Plugin Manager & Uploader** | Upload and install community plugins (`.plugin.js`, `.js`, or `.zip`), toggle active states in `plugins.json`, view/edit JavaScript code, and hot-reload Discord with 1-click. |
| **Discord UI Enhancements & Toggles** | Toggle specialized client-side enhancements: hidden & locked channels styling, ultra-compact mode, auto-collapse member list, auto-collapse server rail, smooth animations, mention glow, and privacy avatar blur. |

## ⚡ Big Distinctions: Discord-Chan vs Vanilla BetterDiscord

| Feature Aspect | Vanilla BetterDiscord | Discord-Chan Studio |
| :--- | :--- | :--- |
| **Engine Architecture** | Mod loader & plugin runtime | **Powered by BetterDiscord Engine** + Visual Discord-Styled Studio |
| **Theme Customizer GUI** | Manual CSS file editing | **Dedicated Control Studio Dashboard** (`Ctrl+Shift+P` & `F11`) |
| **BD Theme & Plugin Customizer** | Manual editing and manual folder moving | **Upload, Customize & Edit Live** with visual color picker, wallpaper replacer, and built-in code editor |
| **Display Modes** | Manual theme swapping | **3 One-Click Modes** (Anime Wallpaper, See-Through Window, Vanilla) |
| **Chat Column Translucency** | Hard-coded per theme | **100% Glass Translucent Chat** with zero solid grey obstruction |
| **Live UI Sliders** | None (edit code) | **Live Sliders** for Wallpapers, Chat, Sidebars, Embeds & Corner Radius (`0px` - `24px`) |
| **Custom Wallpapers** | Edit CSS code URLs | **In-App Wallpaper Selector** with curated presets and local file picker |
| **Extensions Architecture** | Standard JS plugins | **Modular Chrome-Style ZIP Packages** (`manifest.json` + `style.css`) |
| **Theme Portability** | Manual file copying | **1-Click ZIP Theme Export & Import** with embedded wallpapers |
| **Window Clearance Guard** | Prone to panel collisions | **Configurable Top Spacing & Zero-Lag CSS engine** |

## Display Modes

1. **Anime Wallpaper Mode**
   Select from curated high-resolution anime presets (*Kaede to Suzu*, *Whisper Me a Love Song*, *Sakura Minimal*, *Pastel Clouds*, *Neko Mascot*) or browse ANY image file on your computer with real-time thumbnail preview.
2. **See-Through Window Transparency Mode**
   Makes Discord's window transparent so applications and your desktop behind Discord are visible with an adjustable acrylic darkness tint.
3. **Vanilla Discord Client**
   Instantly turn off custom theming to use standard native Discord appearance.
