> [!IMPORTANT]
> **Discord-Chan is 100% Client-Side Aesthetic CSS & BetterDiscord Theme.**
> - ❌ **NOT A NITRO SPOOFER OR UNLOCKER:** This project **does NOT unlock paid Discord Nitro perks** (no server boosting, no bypasses).

## 🚀 1-Command Instant Setup

### 🐧 Linux (One-Liner Install)
Run this single command in your Linux terminal:
```bash
curl -fsSL https://raw.githubusercontent.com/myzert/discord-chan/main/install.sh | bash
```
*Or clone and run manually:*
```bash
git clone https://github.com/myzert/discord-chan.git
cd discord-chan
chmod +x install.sh
./install.sh
```

### 🪟 Windows (PowerShell One-Liner)
Open PowerShell and run:
```powershell
irm https://raw.githubusercontent.com/myzert/discord-chan/main/install.ps1 | iex
```
*Or download and double-click `install.bat`.*

## ✨ Features at a Glance

| Feature | Description |
| :--- | :--- |
| 🌸 **Whisper Me a Love Song Theme** | Dedicated to *Sasayaku You ni Koi wo Utau* (Yori & Himari romance) with a clean pastel pink aesthetic. |
| ⚡ **Zero-Lag & No-Shadow Engine** | Completely eliminates CPU-heavy `box-shadow` and `backdrop-filter: blur` lag. Guaranteed butter-smooth 60 FPS even on virtual GPUs and lightweight hardware. |
| 🪟 **Custom Translucency & Glass** | Independent sliders for Background Darkening, Channel Sidebar Opacity, and Chat Area Transparency. |
| 📏 **Anti-Collision Clearance (Top Spacing)** | Configurable `top-spacing` prevents Discord from colliding with Linux top panels (XFCE / GNOME / KDE) or Windows titlebars. |
| 👤 **Chat Avatar Grid Protection** | Discord's native message layout is preserved—user avatars will never distort, overlap, or misalign. |
| 🎙️ **Voice Call & Speaking Indicators** | Translucent participant video/voice tiles, customizable glowing speaking ring (Sakura Pink, Emerald, Cyan, Violet), and a floating pill call bar. |
| 🐱 **Discord-Chan Neko Mascot Icon** | Custom squircle application icon with a cute anime neko mascot and delicate pink border. |
| 🎛️ **Discord-Chan Studio GUI** | Built-in Control Center with instant preview cards, color picker, wallpaper manager, and keyboard shortcuts. |
| ⌨ **Command Palette (`Ctrl+Shift+P`)** | Quick in-app window command palette to switch palettes and wallpapers instantly. |

## ⌨ Keyboard Shortcuts (Discord-Chan Studio)

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Shift + P` or `Ctrl + P` | 🌸 Open Quick Command Palette |
| `Ctrl + S` | ⚡ Save & Instantly Apply Theme to Discord |
| `Ctrl + R` | 🔄 Restart Discord with Anti-Crash Safe Flags |
| `Ctrl + O` | 📁 Browse Custom Anime Wallpaper from Computer |
| `Ctrl + Q` | ❌ Quit Studio |

## 🤝 Contributing

We warmly welcome anime enthusiasts, theme creators, and developers!
- 🌟 **Star this repository** if you enjoy the theme!
- 🖼️ **Submit New Anime Wallpapers:** Add high-res 16:9 wallpapers into `assets/wallpapers/`.
- 🎨 **Add New Color Palettes:** Propose aesthetic color schemes in `src/studio.py` and `src/theme_engine.py`.
- 🐛 **Report Bugs or Suggest Features:** Open an [Issue on GitHub](https://github.com/myzert/discord-chan/issues).

### How to Submit a Pull Request:
1. Fork the repo: `https://github.com/myzert/discord-chan`
2. Create your feature branch: `git checkout -b feature/anime-theme-update`
3. Commit your changes: `git commit -m "Add new anime preset"`
4. Push to the branch: `git push origin feature/anime-theme-update`
5. Open a Pull Request!
